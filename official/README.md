# M-VAVE factory firmware

`FM-1.fwsc` is M-VAVE's official FM-1 firmware, version 16 (M-VAVE lists it as FM-1_016, published October 21, 2026). It is unchanged, exactly as M-VAVE distributes it.

SHA-256: `d017fb65e70aca97ee29d944470c3515a74581df5c0576bf70de917c7b2b61d5`

It belongs to M-VAVE and is **not** covered by this repository's GPL licence. It's included only so you can go back to the factory firmware: install it with M-VAVE's M-UPGRADE app.
